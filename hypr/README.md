# CachyOS Hyprland configuration

This directory is the canonical CachyOS Hyprland configuration and is linked
from `~/.config/hypr`.

## Trackpad

- Natural scrolling is enabled.
- Tap-to-click and tap-and-drag are disabled.
- Physical click behavior uses clickfinger mapping.
- Scroll factor is set to `0.4`.

## Gestures

- Three-finger horizontal swipe switches workspaces.
- Three-finger swipe up enters fullscreen.
- Three-finger swipe down exits fullscreen.
